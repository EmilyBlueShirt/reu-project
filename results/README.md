# Results

This directory contains the evaluation outputs and analysis generated during the CTI-ATE experiments.

## Contents

Typical files in this directory include:

- Per-example evaluation results
- Precision, recall, and micro-F1 summaries
- False positive and false negative counts
- Error analysis tables
- CSV files used to generate figures

## Metrics

The primary evaluation metrics are:

- Precision
- Recall
- Micro-F1
- Per-example F1

These results support the analysis of LLM failure modes in MITRE ATT&CK technique extraction rather than focusing solely on improving overall performance.
