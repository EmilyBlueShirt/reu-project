# Poster

This directory contains the research poster developed for the 2026 NSF REU in Trustworthy AI and Cybersecurity at the Rochester Institute of Technology.

## Contents

- Final REU poster (PDF)
- Optional editable source files (PowerPoint, Illustrator, etc.)

The poster summarizes the research on failure modes in MITRE ATT&CK technique extraction using large language models, including the evaluation methodology, quantitative results, paired error analysis, conclusions, limitations, and future work.
