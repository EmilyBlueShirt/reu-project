# Data

This directory contains the datasets used for the CTI-ATE experiments.

## Dataset

- `cti-ate.tsv` — CTIBench CTI-ATE benchmark containing 60 cyber threat intelligence reports and their corresponding gold MITRE ATT&CK technique IDs.

## Important

The dataset is included only for research and reproducibility. Please refer to the original CTIBench publication for dataset details and citation.

Reference:

Alam et al. *CTIBench: A Benchmark for Evaluating LLMs in Cyber Threat Intelligence*. NeurIPS 2024.
